# cranebench 0.1.2

Software revision accompanying the revised SoftwareX manuscript.

## Changes

- Corrected exact paired McNemar inference, including the zero-discordance case.
- Added revision campaign outputs and manuscript verification assets.
- Added minimum and revision dependency profiles and cross-platform CI.
- Improved distribution metadata and isolated wheel and source installation checks.

The reported campaign ledgers retain package version `0.1.0`, which identifies
the code state used for those simulations. This release contains the corrected
revision analysis and software validation; it does not claim that the original
campaigns were rerun with version `0.1.2`.
